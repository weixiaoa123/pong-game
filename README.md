# Neon Pong

Neon Pong 是一个无需安装、支持键盘、鼠标和触控的复古街机乒乓球小游戏，也是一套可以交给活动页、个人主页、社群或小商家直接使用的轻量 HTML5 小游戏模板。买家可以以 US$1 起获得标题、配色、署名、难度或部署方式的定制。它基于原生 HTML、CSS 和 JavaScript 构建，不依赖数据库。

## 功能

| 功能 | 说明 |
| --- | --- |
| 三档难度 | 新手、标准、专家 |
| 多种控制 | 方向键、W/S、鼠标和触控 |
| 本地最高分 | 使用浏览器本地存储保存最高分 |
| 轻量部署 | 不需要构建工具、服务器或数据库 |
| 响应式界面 | 适配桌面和移动端屏幕 |

## 本地运行

直接用浏览器打开 `index.html` 即可运行。若浏览器限制本地脚本，可在项目目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
